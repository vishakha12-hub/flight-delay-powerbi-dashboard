# ✈️ Flight Delay & On-Time Performance Analytics

## 📊 Project Overview

This project is an interactive Power BI dashboard created to analyze flight delays and on-time performance.

The dashboard helps identify:

- Airline performance
- Airport delay patterns
- Monthly delay trends
- Flight-hour delay patterns
- On-time, delayed and cancelled flights

## 🛠️ Tools Used

- Microsoft Power BI
- Power Query
- DAX
- Microsoft Excel

## 📁 Dataset

The dataset contains flight-level information such as:

- Flight ID
- Date
- Airline
- Origin
- Destination
- Departure Time
- Arrival Time
- Delay Minutes
- Flight Status
- Distance
- Passengers

## 📌 Dashboard Pages

### 1. Flight Overview

Contains:

- Total Flights
- Delayed Flights
- On-Time %
- Average Delay
- Cancelled Flights
- Airline filter
- Origin filter
- Flight Status filter

### 2. Airline Analysis

Analyzes:

- Flights by Airline
- Average Delay by Airline

### 3. Time Analysis

Shows:

- Monthly Average Delay Trend

### 4. Airport Analysis

Shows:

- Average Delay by Airport

### 5. Flight Hour Analysis

Shows:

- Average Delay by Flight Hour

### 6. Flight Status Analysis

Shows:

- On-Time Flights
- Delayed Flights
- Cancelled Flights

## 📈 Key Insights

The dashboard helps users understand:

- Which airlines have higher average delays
- Which airports experience more delays
- Which months have higher delays
- Which flight hours have higher delay levels
- Overall flight status distribution

## 🎯 Project Objective

The main objective is to convert raw flight data into an interactive dashboard that can help users understand flight performance and identify delay patterns.
